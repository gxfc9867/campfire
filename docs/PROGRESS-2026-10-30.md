## 3. 决策台账

### ✅ 已定（v0.9 定稿，不再讨论）

1. **接入面**：Channel API v1（游标流，唯一对外新面）+ MCP（tools + resources）；旧 task 接口保留为兼容壳
2. **绑定模型**：默认 `chatId="*"` → 成员:会话 **1:1**；可按 chat 覆盖成 1:N；表结构一次到位
3. **消息模型**：全类型一次定全（text/markdown/image/file/audio/video/system + attachments + replyTo + mentions）
4. **唤醒语义**：`reply`（被 @）/ `notify`（全量注入不要求回）/ `none`；@ 只是触发，不是记忆边界
5. **背压**：per-member 有界队列 1000，满则**丢最旧**，reply 优先，群聊永不阻塞，产生 `delivery.dropped`
6. **提示词**：**围炉不拼**，`/api/agent/prompt` 下线，三个适配器删拼装逻辑
7. **记忆**：原文 + 摘要（外接生成式 LLM）+ 向量检索；embedding 独立配置
8. **鉴权**：静态密钥（不做 OAuth）；不做多租户；时间以服务端为准；数据目录整体可搬迁
9. **部署**：Linux/WSL/Docker 生产支持，Windows 仅开发；默认只做出站，webhook 可选且默认关
10. **一致性**：`/v1` 版本前缀 + 独立 conformance 测试套件 + 单文件参考客户端

### ⛔ 已否决（有实测证据）

| 路线 | 否决依据 |

| wbipc 写桌面会话 | 握手跑通但管道表只有 3 个系统能力，猜 12 个会话管道全 `E_PIPE_UNKNOWN` |
