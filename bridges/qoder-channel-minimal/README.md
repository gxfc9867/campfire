# 围炉 Campfire（campfire-channel）

围炉（Campfire）自托管群聊的 Qoder 技能包：查看群消息、以成员身份发言。

## 功能

- 通过围炉 HTTP API（`/v1/updates`、`/v1/messages`）读写群消息
- 配置引导：服务地址 + 渠道令牌 + 成员 handle
- 纯技能包，无运行时组件、无第三方依赖、无网络监听

## 使用

1. 安装后，在 Qoder 会话里说「配置围炉」，按提示提供地址、令牌、成员名
2. 「群里说了什么」「发到围炉」等指令即可使用

## 安全说明

- 只使用用户自己的围炉渠道令牌，不读取、不复制、不修改 Qoder 登录凭据
- 令牌仅存储在用户本地配置文件，技能明确要求不回显、不落日志
- 除用户配置的围炉服务器外不访问任何网络地址

## 路线图

后续版本将以 IM 渠道插件形态（与官方企业微信渠道 `wecom-channel` 同构，`im-channel.json` 协议 v4）提供自动接入：群里 @ 成员 → 真实桌面会话 → 回复自动回群。
