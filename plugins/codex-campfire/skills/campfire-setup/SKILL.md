# 围炉接入设置

把 GPT 桌面会话接入围炉群聊：群里 @它的消息会进**当前这条会话**，回答发回群里。

## 直接接入当前会话

不需要新建会话、不需要把会话改名、不需要给会话起任何特定名字。
只要桌面里除了当前会话还有任意一条别的会话（当后台发话口）即可——一般本来就有。
发话口由配置脚本自动挑，不用你管。

## 铁律：只认「配置码」，不要拆字段

用户发来的往往是一整段话：触发 skill 的话 + 明文「围炉地址」「成员名」（给人核对用）+ 配置码。

- **明文地址和成员名只是让人看得见，不是让你拿去手动拼参数。**
- **唯一执行依据仍是配置码**：从这段话里只提取以 `campfire://setup?` 开头、到行尾/空格为止的那一整串，
  忽略前后所有中文说明和明文地址/成员名，把这一串原样作为 `--code` 参数。
- 不要让用户分别提供地址/令牌/成员名三项。
- 不要去猜配置码里的内容，不要解码、不要拆字段、不要问"地址是什么"。
- 不要修改、截断、重排配置码；原样传给配置脚本。
- 如果整段话里没有 `campfire://setup?...`（例如只有一个 `cf_...` 令牌），告诉他：
  「请回围炉接入设置，点『生成 / 重新生成』，把那一整段话复制过来」。

## 运行一条命令

找到 `configure.mjs`（本插件 `adapter/configure.mjs`，用文件搜索定位绝对路径）。
再用你自己能查会话的工具（如 `list_threads`）取**当前这条会话的 id**（最近活动、你正在其中对话的那条），
作为 `--memberThread` 一并传入：

```
node "<绝对路径>/configure.mjs" --code "<配置码原样>" --memberThread "<当前会话id>"
```

- `--memberThread` 让群消息进当前会话；配置脚本会自动挑另一条不同会话当发话口。
- 如果你确实拿不到当前会话 id，就只传 `--code`，脚本会自动选一条会话当成员会话（仍可用，只是不一定是这条）。

就这一步。配置脚本会自动：解析配置码 → 定好两条会话 → 写配置 → 启动后台适配器 → 验证进程存活。
**不要读脚本内容、不要额外核验进程或日志、不要做任何修复、不要改会话标题或索引文件。** 命令成功即完成。

## 完成后

命令输出会告诉你配好了。你只需转告用户：

> 配好了，回群里 @`成员名` 发句话试试，几秒内会有回复。你当前这条会话就是「围炉成员会话」，能看到一来一回。

如果命令报错：
- "还需要另一条不同会话" → 让用户再新建或打开一条别的会话，再重跑同一条命令。
- "找不到任何会话" → 让用户打开 GPT 桌面端、确保有会话，再重跑。
- 其它报错 → 把报错原文给用户，让他按提示处理；**不要自己改插件里的代码或会话索引**。

## 说明

- 配置在用户目录 `~/.campfire-codex/.env`，不随插件升级丢失；想改配置，重新生成配置码再跑一次本 skill。
- 适配器是后台进程、不显示窗口。
- 永远不要在回复里回显配置码、令牌或密钥。
